How PhishGuard works

PhishGuard analyses the text of a URL. It never visits the website, so analysing a dangerous link is safe. The detection engine extracts security features from the address, runs a set of weighted rules and (optionally) a machine-learning model, then turns the result into a 0–100 risk score.

Risk classification

Likely Safe0 – {{ suspicious_threshold - 1 }}
Suspicious{{ suspicious_threshold }} – {{ phishing_threshold - 1 }}
Likely Phishing{{ phishing_threshold }} – 100

Each rule that fires adds points to the score. A recognised legitimate domain subtracts points. Two or more high-risk indicators always produce at least a "Likely Phishing" result; one high-risk indicator always produces at least "Suspicious".

Machine learning (optional)

When a trained scikit-learn model is available, its phishing probability is blended with the rule score (60% rules, 40% model). Train one with python ml/train_model.py.

Limitations

  • URL-based analysis cannot guarantee that a website is completely safe.
  • Attack techniques change over time and rules need updating.
  • A compromised legitimate website can host phishing pages.
  • The result is a risk assessment, not a guaranteed verdict.
